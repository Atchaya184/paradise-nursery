
# Paradise Nursery

## Online Plant Shopping Application

Paradise Nursery is an online shopping application
where customers can browse and purchase beautiful
indoor plants.

## Features

- Beautiful landing page
- About Us page
- Three plant categories
- 18 unique plants
- Plant images, descriptions and prices
- Add to Cart functionality
- Dynamic shopping cart count
- Increase and decrease quantities
- Remove plants from cart
- Automatic total price calculation
- Checkout Coming Soon message
- Continue Shopping functionality

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS
- Redux Toolkit
- React Redux

## Installation

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

npm install

4. Start the application:

npm run dev

5. Open the local URL shown in the terminal.
